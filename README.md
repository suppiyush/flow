# Flow

Flow is a no-code workflow automation platform that empowers users to create complex workflows through an intuitive drag-and-drop interface.

## Key Features:

- **Type-Safe APIs with tRPC**: Ensures end-to-end type safety between frontend and backend.
- **Background Job Processing with Inngest**: Handles asynchronous tasks and event-driven workflows reliably.
- **Secure Authentication with Better Auth**: Provides robust user authentication and authorization.
- **Payment Integration with Polar**: Manages subscriptions and payments seamlessly.
- **Schema Validation with Zod**: Validates data structures and API inputs for reliability.

## Development Setup

1. Clone the repo

```bash
git clone https://github.com/suppiyush/flow
```

2. Install the dependencies

```bash
npm install
```

3. Start the next.js server

```bash
npm run dev
```

5. Start the inngest server

```bash
npm run inngest:dev
```
